# UDD Tunnel Lab Web

Sitio estático inicial para UDD Tunnel Lab.

## Archivos
- `index.html`: estructura y contenido editable.
- `styles.css`: paleta, layout y estilo visual.
- `script.js`: menú móvil.
- `assets/logo-udd-tunnel-lab.svg`: logo temporal editable.

## Qué reemplazar después
1. Cambiar el logo temporal por el logo oficial del equipo.
2. Reemplazar los placeholders de sponsors por logos reales.
3. Agregar fotos y bios reales en la sección `Quiénes somos`.
4. Cambiar el email del formulario en `mailto:contacto@uddtunnellab.cl`.
5. Agregar renders/fotos en `Nuestra máquina`.

## Publicación rápida
Puedes subir esta carpeta a GitHub Pages, Netlify, Vercel o al servidor de la universidad.
